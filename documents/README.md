# Synthetic policies

`synthetic/` содержит пять вымышленных политик доставки в TXT и PDF.
Это учебные правила, не реальные юридические документы и не сведения о текущих заказах.
Загружайте один формат каждой политики, чтобы не дублировать контекст.

Пересоздать PDF из TXT из корня: `backend/.venv/bin/python documents/generate_pdfs.py`.
PDF содержат извлекаемый английский текст; вопросы можно задавать по-русски.
Пример загрузки и ограничения: [phase-05](../docs/phase-05.md).
